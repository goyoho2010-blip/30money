# 수급 흔적 레이더 (Streamlit)

KOSPI·KOSDAQ 일봉에서 거래량과 거래대금이 평소보다 두드러진 종목을 찾는 개인용 분석 도구의 첫 버전입니다. 종목의 실제 매수 주체나 '세력'을 판별하지 않으며, 조건에 맞는 수급 이상 징후 후보를 표시합니다.

## 기본 검색

- 최신으로 확인 가능한 일봉 기준으로 종가 3만 원 이하 종목 검색
- 1만 원 이하 / 1만~3만 원 구간 분리
- 최근 60거래일 차트 및 거래량 급증일 표시
- 관심 종목 직접 추가 및 삭제
- 검색 결과 CSV 저장
- CSV/XLSX 업로드 분석 기능
- 장마감 매도 검토: 보유 수량·평균 매입가 반영, 평가손익, 5일 평균·거래량·종가 위치·OBV 기반 점검 항목 정리
- 장마감 점검표에서 개인 판단(보유/일부 매도 검토/매도 검토/추가 관찰)과 메모 기록, CSV 저장

## 실행 방법 (Windows)

1. Python 3.10 이상을 설치합니다.
2. 압축을 풀고 해당 폴더에서 명령 프롬프트를 엽니다.
3. 아래 명령을 차례로 실행합니다.

```bat
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 Streamlit 주소(보통 `http://localhost:8501`)를 열면 됩니다.

## Streamlit Community Cloud 배포

GitHub 저장소에 `app.py`, `requirements.txt`, `README.md`를 올리고 Streamlit Community Cloud에서 저장소와 `app.py`를 선택해 배포합니다. 관심 종목 파일은 `watchlist.json`에 저장되며, 무료 클라우드 재시작·재배포 뒤에도 유지해야 하는 운영 단계에서는 영구 저장소를 연결하는 것이 좋습니다.

## 자동 데이터 조회

자동 전 종목 조회는 한국거래소 KRX Open API의 `유가증권 일별매매정보`와 `코스닥 일별매매정보`를 사용합니다. KRX Data Marketplace 회원가입 뒤 **API 인증키 신청 및 두 서비스의 이용 신청**을 하고, KRX 관리자 승인을 받아야 자동 조회가 작동합니다. KRX 안내에 따르면 인증키 신청과 개별 API 이용은 승인 절차를 거칩니다.

신청 안내: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp

인증키는 앱 사이드바 입력란에 넣거나, 배포 앱의 Secrets에 `KRX_API_KEY`로 등록합니다. 채팅으로 키를 보낼 필요가 없습니다. KRX 인증키 없이도 CSV/XLSX 업로드 분석은 사용할 수 있습니다.

## 장마감 매도 검토

`장마감 매도 검토` 탭에서 보유 종목, 수량, 평균 매입가를 입력하면 최신 종가 기준 평가손익과 기술 점검 항목을 함께 볼 수 있습니다. 판단 칸과 메모는 사용자가 직접 입력하고 점검표를 CSV로 저장할 수 있습니다. 보유정보·판단은 앱 세션에 저장되므로, 기록을 남기려면 매일 CSV를 내려받아 보관해 주세요.

현재 연결한 KRX 일별매매정보는 일봉 가격·거래량·거래대금 분석에 사용합니다. OBV는 종가와 거래량으로 계산합니다. 기관·외국인 순매수는 현재 승인받은 일봉 API에 포함되지 않아 별도 CSV/XLSX 자료가 있을 때 선택적으로 올릴 수 있습니다. CVD는 체결별 매수·매도 주도 데이터가 필요해 이 버전에서는 계산하지 않습니다.

선택 수급자료 열 예시: `날짜, 종목코드, 기관순매수, 외국인순매수` (날짜는 선택). 기관·외국인 값은 순매수 수량 또는 순매수 금액 중 한 종류로 통일해 올려 주세요.

첫 자동 조회는 최근 거래일별로 KOSPI·KOSDAQ 데이터를 모으므로 다소 시간이 걸릴 수 있습니다. 같은 조건에서는 30분간 캐시하며, 사이드바의 **데이터 새로고침** 버튼으로 다시 조회할 수 있습니다.

## CSV/XLSX 업로드 열

필수 열: `날짜, 종목코드, 시가, 고가, 저가, 종가, 거래량`

선택 열: `종목명, 시장, 거래대금, 등락률`

한국어 또는 영문 표제(예: `date, ticker, open, high, low, close, volume`)를 사용할 수 있습니다. 20거래일 평균 거래량을 계산하려면 종목별로 최소 21거래일 이상의 데이터가 권장됩니다.

## 검색 점수 기준

- 거래량 급증: 당일 거래량이 직전 20거래일 평균의 사용자 설정 배수 이상
- 급증 후보: 거래량 급증 및 설정 최소 거래대금을 동시에 충족
- 참고 점수(0~5): 거래량 배수, 거래대금, 종가가 시가 이상인지, 최근 5일 수익률로 구성

이 기준은 주문 흐름·투자자별 매매를 직접 분석하지 않습니다. 점수나 표시는 매수·매도 권유가 아닙니다.
